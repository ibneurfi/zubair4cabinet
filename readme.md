# Zubair for AMUSU Cabinet Member — Netlify Drop

This package follows the supplied campaign HTML: AMU maroon and yellow, campaign hero, About section, four manifesto areas, PDF download, student request form, and footer.

## Before deploying
1. Add Zubair's photo at `assets/zubair-photo.jpg` (JPG format). The HTML references this path.
2. Review all manifesto promises and personal statements for accuracy.
3. The form uses the Formspree endpoint included in the supplied file (`https://formspree.io/f/xqppqzln`). Confirm it belongs to your campaign and is active before collecting students' names, phone numbers, halls/departments, and requests. Replace it with your own endpoint if needed.
4. Social links from the source are placeholders (`#`). Replace them with real campaign accounts or remove them before publishing.

## Deploy free on Netlify Drop
1. Download and extract this ZIP.
2. Open https://app.netlify.com/drop and sign in if prompted.
3. Drag the extracted `zubair_amusu_netlify_drop` folder into the upload area. `index.html` must be at the folder's top level.
4. Netlify will publish it and show a `*.netlify.app` URL.
5. Test the website on a phone. Check the portrait, manifesto PDF download, mobile menu, and form submission.

No custom domain is needed. Netlify's free-plan limits and terms can change.
